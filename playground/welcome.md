# Welcome to GhostIDE 👻

A fully offline AI code editor, powered by a local Qwen2.5-Coder 7B
running in llama.cpp. Nothing you type leaves this machine.

## Try it
1. Open `fib.py` and put your cursor at the end of the stub - pause for a
   second and watch for a grey inline suggestion. **Tab** accepts it,
   **Esc** dismisses it.
2. Ask the chat (right panel) things like "write a function that reverses
   a string" - then use **Insert at cursor** under any code block.
3. **Ctrl+S** saves. The file tree on the left is a real folder
   (the playground), so everything persists.

## Shortcuts
- Tab: accept autocomplete suggestion
- Esc: dismiss suggestion
- Ctrl+S: save file
- Enter in chat: send (Shift+Enter for a newline)
